# Juloass public Maven repository

Static, anonymous Maven repository for the small public Java libraries maintained under the `Juloass` GitHub account.

```groovy
repositories {
    maven { url = uri('https://raw.githubusercontent.com/Juloass/maven/main/releases') }
}
```
